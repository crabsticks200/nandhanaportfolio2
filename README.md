# Nandhana Neminathan: FBLA Career Portfolio

An interactive portfolio: a plane, a globe of ten travel stops, then a full-screen in-flight slide deck.

## Run it in a GitHub Codespace
1. Push this folder to a GitHub repo.
2. Click **Code > Codespaces > Create codespace**.
3. The site starts automatically on port 8000 and opens in a preview. (Or run `python3 -m http.server 8000` and open the forwarded port.)

## Run it on your computer
Open a terminal in this folder and run `python3 -m http.server 8000`, then visit http://localhost:8000.

## Publish it with GitHub Pages
Repo **Settings > Pages**, choose branch `main` and folder `/ (root)`. Your site will be at `https://<your-username>.github.io/<repo-name>/`.

## Editing
- Click **Edit** (top right) to change text, replace photos, add photos, and move, zoom or rotate them.
- Edits are saved in **your browser only** (localStorage) on the computer you use. They do not change the files and other visitors do not see them. To make a change permanent for everyone, edit `index.html` (text) or replace files in `images/`.
- Photos live in `images/`. All slide content is in `index.html`.
